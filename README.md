# AI TOOK MY JOB

Сатирический браузерный 3D-симулятор офисной смены в 2027 году. ИИ автоматизировал Auto Division и оставил одного человека разбираться со сбоями. В первой смене принтер PR-404 требует картридж, чтобы распечатать справку о ненужности людей.

## Запуск

Нужны Node.js 22.12+ и браузер с WebGL 2.

```sh
npm ci
npm run dev
```

Vite выведет адрес локального сервера. Для проверки production-сборки:

```sh
npm run build
npm run preview
```

Готовый сайт собирается в `dist/`. Игра загружает ресурсы из сборки, использует локальное хранилище браузера и не требует платных API.

## Смена 01 · Сбой печати

1. Нажмите «Начать смену». Подойдите к жёлтому столу и наведите прицел на картридж.
2. Возьмите его и пройдите по жёлтой линии к принтеру PR-404. Наведите прицел на корпус принтера и установите картридж.
3. Дождитесь печати. Экран результатов покажет время смены. Личный рекорд и настройка звука сохраняются в браузере.

| Действие | Компьютер | Сенсорный экран |
| --- | --- | --- |
| Движение | WASD или стрелки | Джойстик слева |
| Обзор | Мышь с захватом курсора. Если захват недоступен, перетаскивание по сцене | Свайп по сцене |
| Взять предмет или использовать принтер | E | «Действие» |
| Бросить предмет | Q или левая кнопка мыши при захваченном курсоре | «Бросить» |
| Отпустить предмет | F | «Отпустить» |
| Прыгнуть | Пробел | «Прыжок» |
| Пауза | Esc или кнопка паузы | Кнопка паузы |

## Архитектура

`src/main.ts` запускает модули. `core/Game.ts` связывает их и управляет состояниями меню, смены, паузы и результатов.

| Каталог | Ответственность |
| --- | --- |
| `core/` | Цикл 60 фиксированных шагов симуляции в секунду, отрисовка через requestAnimationFrame |
| `rendering/` | Three.js, WebGL 2, камеры, тени, процедурные примитивы и GLTFLoader |
| `physics/` | Rapier WASM, гравитация, коллайдеры и группы столкновений |
| `player/` | Контроллер капсулы, обзор, прыжок, клавиатура и мультитач |
| `interaction/` | Луч из центра экрана, перенос динамического тела, сброс и бросок |
| `npc/`, `animation/` | Состояния HR-01, маршрут, реакция на игрока и броски, анимация головы и рук |
| `tasks/`, `events/` | Прогресс смены, время печати и случайные сбои освещения |
| `audio/` | Синтез коротких сигналов и воспроизведение через Howler |
| `ui/` | Меню, HUD, подсказки, пауза и результаты |
| `save/` | Версионированные локальные настройки и личный рекорд |
| `platform/` | Определение сенсорного ввода и адаптер для будущего клиента Telegram |
| `world/` | Офис, точки спавна и процедурные предметы |

Эмблема на принтере загружается из оригинального процедурного GLB. Воспроизводимый генератор находится в `scripts/generate-badge.py`. Коллайдеры создаются отдельно от моделей, чтобы замена временной геометрии на GLB не меняла игровой баланс.

На сенсорных экранах ограничены плотность пикселей, бюджет кадра и разрешение теней. В игре один источник динамических теней. Геометрия коробок и материалы повторно используются. Адаптер Telegram вызывает `ready`, `expand` и тактильную отдачу при наличии `window.Telegram.WebApp` в окружении.
