# AI TOOK MY JOB

- Работайте в этом репозитории. Команды проверки — `npm run typecheck`, `npm run build` и локальный запуск через `npm run preview`.
- Сохраняйте строгую типизацию. Связывайте игровые системы в `core/Game.ts`. Three.js отвечает за представление, Rapier — за коллизии и координаты тел, `tasks` — за состояние задания.
- Используйте фиксированный шаг для симуляции. Обновляйте графические трансформации из физических тел после шага Rapier. Проверьте, что пауза замораживает игровое время.
- При изменении предметов или окружения проверяйте соответствие мешей и коллайдеров, доступность обоих этапов задания и повторный запуск смены.
- При изменении управления проверяйте мышь с захватом, перетаскивание без захвата и сенсорные действия. Сохраняйте автономный запуск в обычном браузере без SDK Telegram.
- Используйте оригинальные ассеты. Размещайте временные модели и данные сцены в `src/world`. Расширяйте GDD и roadmap при изменении механик или границ этапа.
- Держите этапы разработки раздельно. Перед переходом убедитесь, что критерии текущего этапа проверены, и внесите результат в `docs/QA.md`.
