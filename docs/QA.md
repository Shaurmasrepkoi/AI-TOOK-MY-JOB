# Проверка этапа 1

Проверена production-сборка Vite на Node.js 24.22.0. Браузерные сценарии прогнаны в установленном Google Chrome через Playwright на macOS. Прогон использовал интерфейс и реальные модули игры, а часы кадра управлялись тестом для воспроизводимого движения и таймеров.

| Проверка | Результат |
| --- | --- |
| Строгая проверка TypeScript и сборка | `npm run build` прошла, `dist/` отдаётся локальным Vite preview |
| Загрузка офиса | WebGL 2 отрисовывает меню и игру, браузер загрузил эмблему GLB |
| Мышь и клавиатура | Справка открывается, курсор захватывается при старте, Escape ставит смену на паузу, продолжение возвращает захват и время |
| Резервный обзор | При недоступном захвате курсора обзор работает перетаскиванием. Удержание движения вперёд упирает игрока в стол |
| Физические действия | Картридж подбирается со стола, падает после отпускания и подбирается с пола. После броска меняется положение маркера. Прыжок меняет высоту обзора |
| Смена PR-404 | Подбор обновляет задачу, картридж устанавливается в принтер, печать завершает смену и сохраняет результат. Повторный старт восстанавливает исходную задачу |
| Случайные события | Во время активной смены приходит сообщение о сбое |
| Звук и сохранение | Аудиобуфер воспроизводится через Web Audio. Настройка звука сохраняется после перезагрузки. Лучшее время отображается в меню |
| Сенсорный экран 390 × 844 | Джойстик, свайп, подбор, бросок и пауза работают. HUD и кнопка звука размещаются без перекрытия |
| Альбомный экран 667 × 375 | Кнопки стартового меню помещаются над нижней строкой |
| Ошибки выполнения | В сценариях не было необработанных исключений, ошибок консоли и неуспешных HTTP-ответов |

## Известные ограничения

- Chrome проверен на macOS, сенсорный ввод проверен в эмуляции. Производительность на физических телефонах и среда Telegram остаются в roadmap.
- Vite предупреждает о размере модулей Three.js и Rapier. Основные JS-ресурсы занимают суммарно около 1 МБ после gzip, из которых пакет Rapier со встроенным WASM занимает около 842 КБ. Во время инициализации Rapier compat 0.19.3 выводит собственное предупреждение об устаревшем формате параметров WASM. Инициализация и симуляция проходят.
- В объём этого этапа входит одна смена и одна локация.
