# AI TOOK MY JOB · Living Office 0.2

Сатирический браузерный 3D-симулятор офисной смены в 2027 году. ИИ автоматизировал Auto Division и оставил одного человека разбираться со сбоями.

## Запуск

Нужны Node.js 22.12+ и браузер с WebGL 2.

```sh
npm ci
npm run dev
```

Vite выведет адрес локального сервера. Для production-сборки:

```sh
npm run build
npm run preview
```

Готовый сайт находится в `dist/`. Для прохождения смены достаточно ресурсов сборки и браузера. Настройки и рекорд хранятся локально.

## Смена 01

| Заявка | Что сделать |
| --- | --- |
| PR-404 | Возьмите оранжевый картридж на жёлтом столе. Поставьте его в принтер в правом проходе и дождитесь справки. |
| BREW-OPS | Возьмите фильтр на зелёном столе рядом с терминалом. Установите его в кофемашину в зоне отдыха и нажмите кнопку заваривания. |
| HR-01 | После сообщения о зависании найдите робота в центральном проходе, снимите блокировку действием и дождитесь перезагрузки. |

Печать открывает отчёт и сохраняет лучшее время до получения справки. Кофемашину и робота можно обслужить до печати или вернуться к ним через «Вернуться в офис». Отчёт доступен в меню паузы после печати. «Новая смена» возвращает предметы и оборудование в исходное состояние.

В офисе также можно переключить свет на аварийный, открыть серверную, пролистать терминал, получить батончик и проверить, как летают архивные коробки.

| Действие | Компьютер | Сенсорный экран |
| --- | --- | --- |
| Движение | WASD или стрелки | Джойстик слева |
| Обзор | Мышь с захватом курсора или перетаскивание по сцене | Свайп по сцене |
| Взять или использовать | E | «Действие» |
| Бросить | Q или левая кнопка мыши при захваченном курсоре | «Бросить» |
| Отпустить | F | «Отпустить» |
| Прыгнуть | Пробел | «Прыжок» |
| Пауза | Esc или кнопка паузы | Кнопка паузы |

Графика и громкость настраиваются в меню и на паузе. Low ограничивает разрешение кадра и отключает динамические тени и пыль. Medium включает тени, контактное затенение и пыль. High увеличивает разрешение и добавляет bloom. Начальный профиль на компьютере — Medium, при сенсорном управлении — Low. Музыка и эффекты регулируются отдельно. Звуковая сцена запускается при начале смены после действия пользователя.

## Архитектура

| Каталог | Ответственность |
| --- | --- |
| `core/` | Связь модулей, экраны игры, 60 фиксированных шагов симуляции в секунду |
| `rendering/` | Three.js, WebGL 2, профили качества, tone mapping, объединение статических мешей и атмосферные эффекты |
| `physics/`, `player/` | Rapier WASM, коллизии, капсула игрока, обзор и клавиатурный и сенсорный ввод |
| `interaction/` | Луч из прицела, перенос динамических тел, бросок и использование оборудования |
| `npc/`, `animation/` | Патруль HR-01, обнаружение препятствий, цифровое лицо и анимации |
| `tasks/`, `events/` | Три заявки смены и сбои электросети |
| `audio/` | Оригинальные процедурные звуки и музыка через Howler |
| `ui/`, `save/` | Экраны, HUD, настройки и личный рекорд |
| `platform/` | Сенсорный ввод и вызовы `ready`, `expand` и тактильной отдачи при наличии `window.Telegram.WebApp` |
| `world/` | Офис, мебель, станции и процедурные физические предметы |

Офис, надписи и звук созданы в коде. Эмблема загружается из оригинального GLB, который можно воспроизвести скриптом `scripts/generate-badge.py`. Rapier использует отдельные коллайдеры, включая подвижную дверь, и синхронизирует её позу с Three.js после шага симуляции.
